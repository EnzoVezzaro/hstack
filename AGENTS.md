# Repository guidance

This repository publishes H Stack's reusable skills and documentation. H Stack is designed for work across multiple repositories; examples of project work must use an explicit `<project>` placeholder or name every target repo.

## Keep the reference accurate

- Read `CONTRIBUTING.md`, `docs/skill-contract.md`, and the relevant skill and docs before editing.
- Keep new or changed routes aligned across `skills/hstack/SKILL.md`, `README.md`, and `docs/hstack-v5.md`; update `docs/source-skills.md` and `docs/workflows.md` when they apply.
- Do not present a designed workflow as historical usage unless the cited evidence supports that claim.
- Keep per-user model assignments in consumer projects' `AGENTS.md` files. This repository's `AGENTS.md` is contributor guidance, not a personal `## hstack models` map.
- Preserve unrelated work and do not commit, push, merge, or publish unless explicitly asked.
