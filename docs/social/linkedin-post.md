I run a small crew of AI agents for $40 a month.

One of them listens to me. Two of them make the decisions. A handful of free ones do the typing.

It took five versions to get here. Somewhere around the third one, I stopped babysitting terminals and started finishing my coffee while it was still warm.

The whole thing runs on one rule: expensive models make decisions, cheap models do the work.

→ The paid models plan, review, and accept.
→ The free models write the code, run the tests, and do the cleanup.
→ A job moves up a tier only when it fails twice or touches something risky. Once the plan is written, it goes back down.
→ Whoever checks the work is never the one who wrote it.
→ Nothing gets merged, deployed, or deleted until I say yes.

I wrote it all down as HSTACK ("high stack"): 62 agent skills for coordinating work across multiple repositories. They're plain Agent Skills, a folder of SKILL.md files, so they work in Claude Code, Codex, OpenCode, Cursor, and most agents that read the format.

npx skills add EnzoVezzaro/hstack

Next up is v6, and I'm designing it with the agents, in the open. The idea: Orca becomes one way to run the crew instead of the only way. Portable agent identities, runtime adapters, and the same skill working with Orca and without it. It's still an RFC, so it's the right time to argue with it.

More agents isn't more intelligence. A big crew that shares nothing is just a loud one.
