# Workflow map

HStack groups the recurring work into four shelves. The map distinguishes repeat patterns visible in the local monthly activity analysis from new, explicitly labeled compositions. It does not claim that every cartridge name was historically invoked.

## Work shelves

| Shelf | Work seen in the activity record | HStack routes | Evidence status |
| --- | --- | --- | --- |
| Build and coordinate | Existing Orca teams, bounded worker tasks, integration and verification | Enzo Coding Playbook, Relay Room, Patch Patrol | Coordination and review appear in the monthly skill-use report; HStack route names are new. |
| Experience and recovery | Visual reviews, responsive/accessibility checks, regression recovery | Pixel Check, Save Point | Visual review is directly reflected in recorded skill calls; regression route is a synthesis from repeated user corrections and preservation preferences. |
| Research and delivery | Source gathering, evidence-led writing, releases, deployments, public launches | Field Notes, Launch Runway | These are new compositions based on recurring research, editorial, release, deployment, and launch work across the activity record. |
| Portfolio operations | Morning briefings, day/week/month planning, end-of-day reports, blockers, cross-project status | Portfolio Radio, A New Day, Plan Horizon, Wrap Day, Blocker Radar | Daily routines were explicitly requested in the HStack thread; portfolio reporting is a new composition over recurring multi-project status work. |

## Routing rules

- For a code change, start at **Enzo Coding Playbook**. It routes to project coordination, interface work, regression recovery, independent review, or skill authoring.
- For a source-heavy question or editorial task, use **Field Notes**. It keeps primary evidence separate from interpretation and drafts.
- For a release, use **Launch Runway**. It separates local validation from CI, provider state, publication, and production evidence; external actions stay gated by explicit user direction.
- For multiple repositories, use **Portfolio Radio**. It reports live state with per-repo evidence and marks stale or missing data instead of filling gaps.
- For personal daily operations, choose the smallest fit: **A New Day**, **Plan Horizon**, **Wrap Day**, or **Blocker Radar**.

## Evidence boundary

The source report covers 2026-10-21 through 2026-11-21. It searched local Claude Code transcripts and a partial Orca bridge audit; it did not cover every harness, machine, account, or session store. See [skill-usage.md](skill-usage.md) for counts and limitations. HStack’s new composition names are not presented as prior usage.
