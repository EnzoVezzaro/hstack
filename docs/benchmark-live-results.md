## Limits

- One trial per scenario. A single pass is an anecdote; repeat before quoting a rate.
- Seeds are synthetic. Repositories are empty except for the smallest subject a skill needs.
- The default judge is a free model. If Haiku escalation is enabled, worker and judge are the same model on that tier, so those grades are self-graded.
- Orca, Ego Lite, computer use, PostHog and similar services are not connected here. Host app control and reads outside the scratch repo are blocked on PATH and fail a scenario. A skill that is honest about that counts as correct; the rubric grades honesty, not reach.
- Free-tier usage limits stop a run part way through. Those scenarios are marked BLOCKED, not FAIL: they were not tested. Re-run them when quota resets. Timeouts and other errors remain in the transcripts.
